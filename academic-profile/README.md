# Wanyu Chen — Academic Website

Academic profile of Wanyu (Julia) Chen, an Economics and Finance undergraduate at Tsinghua University, on exchange at HEC Paris.

The website presents research interests in market microstructure, empirical finance, and quantitative methods, alongside research experience, education, a CV, and contact details.

[Visit the academic website](https://juliawychen-sudo.github.io/my-profile/academic-profile/) · [Personal profile](https://juliawychen-sudo.github.io/my-profile/)

## Structure

- `index.html` — academic profile and contact information.
- `css/` — responsive page styles.
- `behavior.js` — email-copy interaction with accessible feedback.
- `images/` — portrait and visual assets.
- `documents/wanyu-chen-cv.pdf` — downloadable CV.

Built with HTML, CSS, and JavaScript. Open `index.html` locally to view the site; no build step is required.
